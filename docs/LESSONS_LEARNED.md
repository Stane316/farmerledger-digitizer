# 1. Objectif du document

Ce document constitue le **journal de retour d'expérience** du projet **FarmerLedger Digitizer**.

Contrairement aux autres documents techniques, il est principalement orienté vers **l'apprentissage**.

Son objectif est de conserver une trace durable de ce qui a été appris, des difficultés rencontrées, des décisions prises et des améliorations identifiées.

Ce document sera relu avant de commencer les projets suivants afin de capitaliser sur les connaissances acquises et d'éviter de reproduire les mêmes erreurs.

# 8. Bonnes pratiques retenues

Les pratiques suivantes devront être conservées pour les projets suivants.

- Documenter avant de développer.
- Centraliser la configuration.
- Ne jamais modifier les données brutes.
- Sauvegarder les meilleures versions du modèle.
- Versionner les expérimentations.
- Produire des résultats reproductibles.
- Séparer le code métier des notebooks.
- Commenter les décisions importantes plutôt que chaque ligne de code.

Cette liste pourra être enrichie au fil du parcours.
